# ChatterBox 💬

A real-time chat application built with React and Socket.IO where users can exchange messages and see live online statuses. Includes unread message indicators just like modern chat apps.

## 🛠 Tech Stack

- **Frontend**: React, Tailwind CSS
- **Backend**: Node.js, Express, Socket.IO
- **Communication**: WebSockets via Socket.IO

## 🚀 Features

- Real-time messaging
- Online user listing
- Unread message count per user
- Simple UI using Tailwind CSS

## 📦 Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/kvarun007/ChatterBox.git
cd ChatterBox
```

### 2. Start the server

Make sure you have Node.js installed.

```bash
cd server
npm install
node index.js
```

The server will run on `http://localhost:4000`

### 3. Start the client

```bash
cd frontend/my-chatapp
npm install
npm start
```

The client will run on `http://localhost:3000`

## 🧪 Testing Locally

1. Open multiple browser tabs or windows
2. Enter different usernames when prompted
3. Start chatting live between users
